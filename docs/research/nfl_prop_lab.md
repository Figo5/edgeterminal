# NFL player prop projection lab (research only)

Run `./.venv/bin/python -m edgeterminal.nfl_prop_lab --seal` from the repository root after checking the weekly player-stat cache and the archived SportsGameOdds capture. This command makes no provider requests. It writes a local JSON report and, only when explicitly requested, an immutable prop-only freeze. The research API board reads archived quotes and that freeze; it never runs fitting or changes the game-model PASS policy.

## Data and cutoff

The five targets are passing yards, rushing yards, rushing attempts, receptions, and receiving yards. Labels come from nflverse `stats_player_week` CSVs for 2022–2026; the Week 3 run discards every row at or after 2026 Week 3. Feature construction stages all players in a season/week, then updates player, team, and opponent history after the entire week. This conservative boundary means a Sunday game cannot use a Thursday result from the same week. Eligibility uses prior-game opportunity only: at least 10 prior average passing attempts for passing yards, one carry for rushing markets, or one target for receiving markets. This avoids diluting error scores with active players who have no plausible quoted opportunity. Player identity uses GSIS `player_id`; archived SportsGameOdds names are joined by normalized name plus exact canonical team, and ambiguous/unmatched identities are excluded.

Features are rolling last-three and last-five targets, receptions, receiving yards, carries, rushing yards, passing attempts, and passing yards; prior game count; prior target/carry share; prior team pass/rush volume; prior opponent allowed outcome; scheduled home status, rest, days since prior appearance, week, and position. No current-game stat, odds, or game result enters a feature. Market-specific rolling baseline, standardized Ridge, and histogram gradient boosting are compared. Each 2024 and 2025 week is predicted after fitting on earlier weeks only. The lowest 2024 MAE chooses a model separately for each market; 2025 is a reported holdout and does not choose the model. The Week 3 model fits all rows before 2026 Week 3. Uncertainty is the selected model's 2024 walk-forward residual standard deviation, used as a single Normal predictive scale per market; probabilities are uncalibrated research estimates.

## Market comparison and freezing

Only finite, valid-priced, `main` quotes with exactly one over and one under at the identical player, book, market, and line form comparison pairs. Alternate, one-sided, and duplicated main quotes remain in the immutable observations and on the board, without model estimates. Each paired side retains its own price and sportsbook. The forward freeze stores each paired projection, model version, uncertainty, quote ID, line, side, price, observed time, and kickoff, plus dataset hashes and feature version. The SQLite table refuses updates and deletes, has one freeze per source batch, and refuses to extend a batch after its research freeze. The seal command verifies quote identity and refuses the whole slate after its first kickoff. It is separate from the game-model forward tracker. The exact input player CSVs and schedule bytes for the initial Week 3 run are preserved in the compressed archive and SHA-256 manifest under `data/research/`.

The board reports only research estimates and raw model-versus-line differences. It never displays a recommendation, stake, confidence score, expected profit, or official pick.

## Limitations

The nflverse weekly CSVs are current corrected releases, not archived as-of each historic kickoff; earlier results may have been corrected later. Historical training uses temporal week boundaries, but cannot prove the precise byte state that existed then. No snap count, route participation, reliable pregame injury status, or announced starter timestamp is present in the weekly player-stat cache. Actual starting QB IDs and completed-game weather in schedule data are excluded because they can be known only later. Future participation is unknown: a historical row exists only when a player appeared, and Week 3 candidates are projected only if a prior recorded game and unambiguous identity exist. The global Normal residual scale is a rough first uncertainty model; yardage/count tails and player-specific variance are not calibrated. The archived sportsbook snapshot is a single observation, not proof of a broadly available or closing price. Nothing here establishes profitable betting performance.
